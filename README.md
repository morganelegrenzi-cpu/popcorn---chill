# Popcorn & Chill

App iPhone pour suivre mes séries et films à voir.

## Installation
1. Sur github.com : **New repository**, nom `popcorn-and-chill`, en **Public**, puis **Create repository**.
2. **uploading an existing file** : glisser les 7 fichiers (index.html, manifest.json, sw.js, les 3 icônes .png, README.md), puis **Commit changes**.
3. **Settings → Pages** : Source « Deploy from a branch », branche `main`, dossier `/ (root)`, **Save**.
4. Après 1-2 minutes, l'adresse apparaît : `https://<ton-pseudo>.github.io/popcorn-and-chill/`.
5. Sur l'iPhone, ouvrir cette adresse dans **Safari**, bouton **Partager**, puis **Sur l'écran d'accueil**.

## Mise à jour
Remplacer `index.html` dans le dépôt (Add file → Upload files). L'app se met à jour à la prochaine ouverture avec du réseau. Les listes ne sont pas touchées.

## Données
Tout est enregistré sur l'iPhone, dans l'app installée. Pense à faire **Réglages → Exporter mes listes** de temps en temps (fichier à garder dans Fichiers ou iCloud Drive).
